# 微信聊天记录 AI 导出工具

一个面向 Windows Codex 用户的本地微信聊天导出 Skill。用户用自然语言指定
聊天、时间和内容类型，工具会先显示数量预览，再把获准范围打包为适合 AI
读取的 ZIP。

> 这是非官方开源项目，与腾讯、微信或 OpenAI 无隶属或授权关系。
> 仅可用于本人已登录且有权处理的本机账号和聊天数据。

## 下载与安装

普通用户不需要下载源码，也不需要懂 SHA-256。请打开本项目右侧的
**Releases**，只下载：

- `微信聊天导出工具-v1.0.0-Windows.zip`

旁边的 `发行包SHA256.txt` 只是给希望独立核对下载文件的进阶用户使用，
不影响正常安装。安装器会自动校验内部文件，无需手工输入或比较哈希值。

安装步骤：

1. 解压整个 ZIP，不能只拿出其中一个文件。
2. 双击 `双击安装.cmd`。
3. 看到“安装成功”后，完全关闭并重新打开 Codex。
4. 直接对 Codex 说：

   > 导出群聊“项目组”中从 2026-08-01 09:00 到 2026-08-03 18:00 的全部文字和图片。

安装不需要管理员权限。更新时会自动备份旧版；发行包中同时提供“恢复上一版本”
和“卸载”入口。

## 它如何工作

1. 在本机检查微信版本与数据位置；自定义 C/D/E 盘位置可做有范围的只读扫描。
2. 识别消息、会话和联系人数据库，但不会立刻读取聊天正文。
3. 在用户授权后，对指定数据库执行有时间限制的只读密钥验证。
4. 先按类型预览数量；用户确认精确范围后才读取正文。
5. 在本机生成包含 `transcript.md`、`messages.json` 和 `manifest.json` 的 ZIP。
6. 清理临时明文数据库和内存中的密钥缓冲。

## 安全与隐私摘要

- 默认离线、只读，不修改微信数据库。
- 不写入微信进程，不注入 DLL，不 Hook，不保存内存转储，不自动结束微信。
- 数据库密钥不进入命令行、日志、报告或导出包。
- 读取正文、复制附件、发现图片密钥分别需要明确授权。
- 未知微信版本、错误密钥或数据库变化时安全停止。
- 默认隐藏账号内部标识和完整本机路径。
- 导出文件保持在本机，除非用户主动把它上传给 AI 或其他服务。

更完整的说明见 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。
对“为什么需要只读内存”“未知发布者”和安全软件提示的解释见
[docs/FAQ.md](docs/FAQ.md)。

## 兼容性

- Windows 10/11 64 位；
- 已真实验收：Weixin 4.1.12.55；
- 另带 Weixin 4.1.10 只读适配器，每台电脑仍须密码学验证；
- 微信 3.x 可识别常见结构，已知密钥时通过本机隐藏输入使用；
- 其他版本会停止并给出脱敏诊断，不会尝试任意偏移或注入。

详见 [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)。

## 使用者责任

聊天记录可能包含其他人的个人信息、工作机密或受限制数据。使用者应确认自己
拥有处理和分享这些数据的权限，并遵守所在地法律、组织政策和聊天参与者的合理
隐私预期。不要用本工具访问他人账号、绕过设备权限或批量收集未经授权的数据。

## 开发与验证

项目使用 Python 3.11+，主要依赖 `cryptography`。运行测试：

```powershell
python -m unittest discover -s tests
```

当前版本包含 59 项自动测试，并完成最终发行包的隔离安装、自检、磁盘发现、
更新备份、恢复、卸载和损坏包拒绝测试。
