# 微信聊天记录 AI 导出工具

当前公开版本：**v1.0.8**。

这是一个面向非技术用户的 Windows Codex Skill，用于在用户明确授权后，按聊天、
时间和消息类型只读导出本人电脑上的微信聊天记录。默认本地处理，不修改微信数据。

普通用户请在 GitHub 的 **Releases** 页面下载
`微信聊天导出工具-v1.0.8-Windows.zip`，不要下载 GitHub 自动生成的 Source code ZIP。
完整解压后双击 `双击安装.cmd`，重启 Codex 即可。

功能、兼容性、安全边界、输出格式及完整更新记录见
[中文使用说明](README.zh-CN.md)。v1.0.8 自带 Windows x64 离线 SILK 语音解码、
whisper.cpp 和多语言 base 模型。tag 源码与发行包内附源码一致；第三方组件的固定版本、
来源和校验值记录在 `vendor/voice-runtime.json`。
