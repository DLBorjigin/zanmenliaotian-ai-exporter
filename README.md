# 微信聊天记录 AI 导出工具

当前公开版本：**v1.0.6**。

如果遇到问题，欢迎在这里/通过邮箱DulaanBorjigin@outlook.com/通过小红书nTengerKhukhT来肘我，如果我有时间的话，将尽量尝试解决。

这是一个面向非技术用户的 Windows Codex Skill，用于在用户明确授权后，按聊天、
时间和消息类型只读导出本人电脑上的微信聊天记录。默认本地处理，不修改微信数据。

普通用户请在 GitHub 的 **Releases** 页面下载
`微信聊天导出工具-v1.0.6-Windows.zip`，不要下载 GitHub 自动生成的 Source code ZIP。
完整解压后双击 `双击安装.cmd`，重启 Codex 即可。

功能、兼容性、安全边界、输出格式及完整更新记录见
[中文使用说明](README.zh-CN.md)。本 tag 中的源码与 v1.0.6 发行包内附源码一致，
可使用 `scripts/build_release.py` 重新构建。

如需反馈问题，可使用 GitHub Issues，或联系维护者：
`dulaanBorjigin@outlook.com`。
