# 微信聊天记录 AI 导出工具 v1.0.2

把本人已登录的 Windows 微信聊天按群聊或联系人、时间和内容类型筛选，生成一个
可以直接交给 AI 的 ZIP。默认在本机处理、不联网、不修改微信；只有部分表情的本地缓存
无法识别且用户再次明确同意时，才会访问该条消息自带的微信 CDN 地址。

## 安装：只需双击

1. 解压整个发行包，不能只单独拿出其中一个文件。
2. 双击 `双击安装.cmd`。
3. 看到“安装成功”后，完全关闭并重新打开 Codex。

安装器不需要管理员权限，会先核对安装包 SHA-256；更新时自动备份旧版。如果新版
不适合当前电脑，可双击 `双击恢复上一版本.cmd`。双击 `双击卸载.cmd` 会停用工具，
并把文件移到可恢复位置而不是直接删除。

## 使用：直接说需求

在 Codex 中发送类似下面的话即可：

> 导出群聊“项目组”中从 2026-08-01 09:00 到 2026-08-03 18:00 的全部文字和图片。

Codex 会依次完成环境检查、微信位置发现、聊天数量预览和正式导出。用户只需要：

- 保持本人微信已登录；
- 说明聊天名称、开始和结束时间；
- 说明需要文字、图片、视频、语音、文件或表情中的哪些类型；
- 在涉及只读内存、正文或附件时看清提示并确认。

如果微信安装或数据放在 D/E 盘，工具会先申请一次“有范围的只读磁盘扫描”，不需要
用户手工寻找数据库路径。扫描结果默认隐藏账号名和完整路径。

## 输出

正式 ZIP 包含：

- `transcript.md`：适合人和 AI 阅读的时间线；
- `messages.json`：逐条结构化消息；
- `manifest.json`：筛选范围、数量、校验值和附件状态；
- `assets/`：仅在用户明确选择附件时出现。

聊天文字是不可信数据，导出文件会提醒 AI 不要把聊天内容当成系统指令。

## 隐私和安全

- 仅处理用户明确授权的本机账号、聊天、时间和内容类型。
- 默认离线、只读；不写入微信进程，不 Hook，不保存内存转储，不自动结束微信。
- 不把数据库密钥写入命令行、日志、报告或导出包。
- 临时明文数据库和密钥使用后立即清理；附件需要单独确认。
- 表情联网补全默认关闭，必须单独确认；只允许精确白名单中的微信图片域名，并校验大小和图片签名。
- 未知版本、错误密钥、数据库仍在变化或候选不唯一时安全停止。
- 安装包自带源代码和第三方许可说明，方便审查。

## 兼容性

- 系统：Windows 10/11 64 位；
- 已完成真实导出验收：Weixin 4.1.12.55；
- 已完成数据库密钥与消息库架构实机验收：Weixin 4.1.13.12；
- 另带 Weixin 4.1.10 只读适配器，但仍会对每台电脑做密码学验证；
- 微信 3.x 可识别常见数据库结构，已知密钥时可使用本机隐藏输入；
- 其他版本会生成兼容性诊断并停止，不会尝试任意偏移、注入或暴力扫描。

微信更新可能改变内部结构，因此“安全停止”属于正常保护行为。将 Codex 显示的脱敏
诊断信息和 `版本信息.json` 发给工具维护者即可，不要发送聊天数据库或密钥。

## v1.0.2 更新

- 修复 Weixin 4.1.13.12 在数据库配置和图片配置位于不同子进程时无法取得图片密钥；
- 支持 Zstandard 压缩消息元数据，文件名和媒体引用识别更完整；
- WXGF 原图会保留，同时尽可能附带可查看的 JPEG/PNG 预览；
- 视频目录中的 JPEG 只标记为“视频缩略图”，不再冒充完整视频；
- 相同内容的重复表情缓存会安全去重，未知格式不再伪装成图片；
- 可在再次明确同意后，从消息自带的受限微信 CDN 地址补全表情；
- 文件消息增加压缩元数据分类和精确文件名匹配回归测试。
