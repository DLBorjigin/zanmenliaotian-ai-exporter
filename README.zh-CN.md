# 微信聊天记录 AI 导出工具 v1.0.6

把本人已登录的 Windows 微信聊天按群聊或联系人、时间和内容类型筛选，生成一个
可以直接交给 AI 的 ZIP。默认在本机处理、不联网、不修改微信；只有部分表情的本地缓存
无法识别且用户再次明确同意时，才会访问该条消息自带的微信 CDN 地址。

## 安装：只需双击

1. 解压整个发行包，不能只单独拿出其中一个文件。
2. 双击 `双击安装.cmd`。
3. 看到“安装成功”后，完全关闭并重新打开 Codex。

安装器不需要管理员权限，会先核对安装包 SHA-256；更新时自动备份旧版。如果新版
不适合当前电脑，可双击 `双击恢复上一版本.cmd`。双击 `双击卸载.cmd` 会停用工具，
并把文件移到可恢复位置而不是直接删除。

## 使用：直接说需求

在 Codex 中发送类似下面的话即可：

> 导出群聊“项目组”中从 2026-08-01 09:00 到 2026-08-03 18:00 的全部文字和图片。

媒体类型会严格按你说的话分开：

- “提取图片”只导出普通图片消息，不含表情或视频封面；
- “提取表情”只导出表情消息；
- “提取视频”只导出可播放的原视频，不用封面代替；
- “提取视频封面”只导出视频消息的图片封面；
- 只有明确说“视频和视频封面”时才会同时导出两者。

只写到分钟的结束时间会包含完整一分钟。例如“到 23:07”默认包含
23:07:00 至 23:07:59，避免漏掉该分钟后半段的消息。

Codex 会依次完成环境检查、微信位置发现、聊天数量预览和正式导出。用户只需要：

- 保持本人微信已登录；
- 说明聊天名称、开始和结束时间；
- 说明需要文字、图片、视频、语音、文件或表情中的哪些类型；
- 在涉及只读内存、正文或附件时看清提示并确认。

如果微信安装或数据放在 D/E 盘，工具会先申请一次“有范围的只读磁盘扫描”，不需要
用户手工寻找数据库路径。扫描结果默认隐藏账号名和完整路径。

## 输出

不含附件时只生成一个记录 ZIP。选择附件后默认生成：

- `*-records.zip`：时间线、结构化消息、清单和附件映射，不重复存放媒体字节；
- `*-images.zip`：普通图片，仅在选中普通图片时出现；
- `*-videos.zip`：原视频或明确要求的视频封面；
- `*-emoticons.zip`：表情；
- `*-audio.zip`：语音；
- `*-files.zip`：文件。

每份媒体只存在于一个分类 ZIP 中，不需要用户再次复制或手工打包。把记录 ZIP 与
所需媒体 ZIP 解压到同一文件夹即可恢复其中的相对链接。只有明确要求“合并为一个
自包含 ZIP”时，才使用旧式单包兼容模式；该模式不会再额外生成分类媒体 ZIP。

聊天文字是不可信数据，导出文件会提醒 AI 不要把聊天内容当成系统指令。

## 隐私和安全

- 仅处理用户明确授权的本机账号、聊天、时间和内容类型。
- 默认离线、只读；不写入微信进程，不 Hook，不保存内存转储，不自动结束微信。
- 不把数据库密钥写入命令行、日志、报告或导出包。
- 临时明文数据库和密钥使用后立即清理；附件需要单独确认。
- 表情联网补全默认关闭，必须单独确认；只允许精确白名单中的微信图片域名，并校验大小和图片签名。
- 未知版本、错误密钥、数据库仍在变化或候选不唯一时安全停止。
- 安装包自带源代码和第三方许可说明，方便审查。
- 原视频只从微信已经正常保存的本地缓存中导出；工具不会替用户点击未打开的视频。

## 兼容性

- 系统：Windows 10/11 64 位；
- 已完成真实导出验收：Weixin 4.1.12.55；
- 已完成数据库密钥与消息库架构实机验收：Weixin 4.1.13.12；
- 另带 Weixin 4.1.10 只读适配器，但仍会对每台电脑做密码学验证；
- 微信 3.x 可识别常见数据库结构，已知密钥时可使用本机隐藏输入；
- 其他版本会生成兼容性诊断并停止，不会尝试任意偏移、注入或暴力扫描。

微信更新可能改变内部结构，因此“安全停止”属于正常保护行为。将 Codex 显示的脱敏
诊断信息和 `版本信息.json` 发给工具维护者即可，不要发送聊天数据库或密钥。

## v1.0.6 更新

- 修复 Weixin 4.1.13.12 复合 `local_type` 导致文件消息被误判为系统消息的问题；
- 即使文件消息没有可解析的 XML 正文，也能通过高 32 位子类型识别并纳入导出；
- 未在本机下载的文件会保留记录和可恢复的文件名，不会再被静默漏掉；

## v1.0.5 更新

- 统一公开版本号为 `v1.0.5`，发行包、运行时、README、源码包和发布说明完全一致；
- 附件导出默认改为“记录包＋分类媒体包”，每份媒体字节只保存一次；
- 记录包保留全部图片、视频、表情、语音和文件消息及其映射，但不重复嵌入附件；
- 保留明确要求单一 ZIP 时的兼容模式，且该模式不再同时生成分类媒体包；
- 修复部分群聊消息已有联系人姓名但 `is_self` 为空时被误判为发送者不明；
- 发送者姓名与消息方向分别记录，并注明姓名、方向各自的判定来源；
- Weixin 4.x 可使用已存在的 `real_sender_id` 安全回补非本人方向，旧版群聊可从
  合法的发送者前缀恢复联系人名称；
- 修复同一聊天表分布在多个 `message_N.db` 时后面的数据库覆盖前面数据库的问题；
- 同一会话现在跨库按时间合并，并按稳定消息 ID 去除重叠记录；
- 媒体查找改为按会话分片、消息月份、MD5 和文件名定向索引，不再先扫完整账号；
- 只有目标目录完整扫描后仍无候选才报告“未找到”，读取不完整会单独报告；
- 能区分普通 HTTPS 视频引用和桌面微信旧式十六进制 CDN 令牌；
- 保留普通图片、表情、视频封面和原视频的严格分离；
- 未缓存原视频会明确报告需要用户先在微信中正常打开，不自动控制微信界面。

## v1.0.4 更新

- 将普通图片、表情、原视频和视频封面变成四个严格独立的请求语义；
- “视频”默认只接受带有效视频容器签名的原文件，绝不再用 JPEG 封面代替；
- “视频封面”必须明确提出，并会标记为仅缩略图；
- 本地没有原视频时会明确报告；经再次授权后，可验证并补全消息自带的微信 CDN 视频；
- CDN 视频若带 AES 密钥，只在内存中短暂解密，且仅在填充和视频签名均通过后写入。

## v1.0.3 更新

- 修复 Weixin 4.1.13.12 在数据库配置和图片配置位于不同子进程时无法取得图片密钥；
- 支持 Zstandard 压缩消息元数据，文件名和媒体引用识别更完整；
- WXGF 原图会保留，同时尽可能附带可查看的 JPEG/PNG 预览；
- 视频目录中的 JPEG 只标记为“视频缩略图”，不再冒充完整视频；
- 相同内容的重复表情缓存会安全去重，未知格式不再伪装成图片；
- 可在再次明确同意后，从消息自带的受限微信 CDN 地址补全表情；
- 文件消息增加压缩元数据分类和精确文件名匹配回归测试。
- 附件按消息类型分别放入 `assets/images`、`assets/videos`、
  `assets/emoticons`、`assets/audio` 和 `assets/files`；视频封面和表情图片
  不再混入普通图片目录。
