# 兼容性与限制

## 支持环境

| 项目 | 状态 |
|---|---|
| Windows 10/11 x64 | 支持 |
| Weixin 4.1.12.55 | 已完成真实导出验收 |
| Weixin 4.1.13.12 | 已完成独立数据库密钥与消息库架构实机验收 |
| Weixin 4.1.10 | 包含只读适配器，仍需每机验证 |
| 微信 3.x 常见数据库结构 | 可识别；已知密钥时可使用 |
| macOS、手机微信 | 不支持 |
| 未知微信版本 | 安全停止并输出脱敏诊断 |

## 为什么微信更新后可能暂时不可用

微信数据库结构和内存配置可能随版本变化。工具不会把旧版本偏移强行套到新版本，
也不会改用注入或任意候选扫描。4.1.13.12 适配器限定到精确版本和精确 WCDB
配置注册结构，每个数据库都必须以自己的盐和第一页 HMAC 单独验证。遇到未知版本
时停止是安全设计，不代表聊天数据损坏。

## 媒体限制

- 表情默认排除，除非用户明确选择。
- 新版 V2 图片使用与数据库不同的媒体密钥，需要单独授权。
- 已过期、未下载或无法验证的附件会被标记，不会伪造成功结果。
- 语音媒体数据库属于单独数据源，复制前需要额外确认。

## 时间与数量

- 未注明时区的时间按电脑本地时区解释。
- 开始时间晚于结束时间会被拒绝。
- 同名聊天无法唯一确定时，工具会显示脱敏会话 ID 让用户选择。
- 多个 `message_N.db` 会分别验证并按时间合并，避免只导出最近消息。
