# 常见问题

## 它会上传我的微信聊天吗？

工具本身不联网，导出文件只写到本机。只有当用户主动把导出文件上传给 AI、
网盘或其他服务时，数据才会离开电脑。后续处理受对应服务的隐私政策约束。

## 为什么需要读取微信进程内存？

新版微信数据库是加密的。如果用户不知道数据库密钥，工具可在明确授权后，对
本人正在运行的 Weixin 进程做有范围、限时、只读的配置检查。候选密钥只有通过
精确目标数据库的密码学验证才会使用。

它不会写入进程、注入 DLL、Hook、保存内存转储或扫描无关进程。已经知道密钥
的用户可以使用本机隐藏输入方式，不进行进程内存检查。

## 需要管理员权限吗？

不需要。工具在当前 Windows 用户的 Codex Skill 目录中安装，也不能绕过当前
账号的文件或进程权限。

## Windows 或安全软件提示“未知发布者”怎么办？

当前发行包没有商业代码签名证书，因此 Windows 可能显示未知发布者。请确认
下载来源是本项目的正式 Release。普通用户无需手工核对 SHA-256，安装器会自动
检查内部文件；附带的 SHA-256 文件只是进阶用户可选的独立校验方式。

不要为了运行工具关闭杀毒软件或安全策略。如果组织电脑阻止脚本或只读进程
访问，请停止并联系组织管理员；不要尝试绕过策略。

## 它支持所有微信版本吗？

不能保证。已真实验证 Weixin 4.1.12.55，并包含 4.1.10 只读适配器。微信更新
内部结构后，工具会安全停止，等待兼容性更新，而不会冒险尝试旧偏移或注入。

## 群聊里有其他人的消息，可以导出吗？

技术上可以从本人账号中选择群聊，但使用者仍须确认自己有权处理和分享这些内容。
工作群、医疗、财务、教育或含个人信息的聊天尤其应遵守组织政策和适用法律。

## 如何卸载或恢复旧版？

解压后的发行包提供 `双击卸载.cmd` 和 `双击恢复上一版本.cmd`。卸载会把
Skill 移到可恢复位置，不会直接永久删除。
