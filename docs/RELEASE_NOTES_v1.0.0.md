# v1.0.0

首个可公开分发的稳定版本。

## 主要功能

- 使用自然语言选择聊天、时间和消息类型；
- 自动发现标准或自定义磁盘中的微信数据；
- 数量预览后再读取正文；
- 支持文字、图片、视频、语音、文件、链接和可选表情；
- 生成适合人和 AI 的 Markdown、JSON 与校验清单；
- 双击安装、自动备份、恢复上一版和可恢复卸载；
- 临时明文自动清理，密钥不落盘。
