# v1.0.1

兼容性修复版本，新增 Weixin 4.1.13.12 只读适配器。

## 主要变化

- 为 4.1.13.12 的消息、会话和联系人数据库分别识别独立密钥；
- 适配器限定到精确模块版本和 WCDB 配置注册结构；
- 所有候选均须通过所选数据库第一页 HMAC，验证失败即安全停止；
- 不写入微信进程，不 Hook，不注入，不保存内存转储；
- 继续支持 4.1.12.55，并保留 4.1.10 只读适配器。

## 验证

- 62 项自动测试通过；
- 4.1.13.12 的消息、会话、联系人数据库均完成实机密钥验证；
- 消息库架构检查结果兼容，读取消息行数为 0；
- 最终发行包完成隔离安装、更新备份、恢复、卸载和损坏包拒绝测试。

## 安装或更新

下载并解压 `微信聊天导出工具-v1.0.1-Windows.zip`，双击
`双击安装.cmd`，然后完全关闭并重新打开 Codex。安装器会自动校验内部文件并
备份旧版本，普通用户无需手工使用 SHA-256。
