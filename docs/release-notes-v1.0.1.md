# v1.0.1 发布说明

本版本新增 Weixin 4.1.13.12 的只读数据库密钥适配器。

- 已在真实的 4.1.13.12 环境中分别验证消息、会话和联系人数据库；
- 支持在数据库通过验证后，按单独授权取得并验证 V2 图片媒体密钥；
- 已完成消息库架构检查，未读取消息行；
- 适配器限定到精确版本和精确 WCDB 配置注册结构；
- 每个候选密钥都必须通过所选数据库第一页的 HMAC 校验；
- 不写入微信进程，不 Hook，不注入，不保存内存转储，不自动结束微信；
- 继续支持 4.1.12.55，并保留 4.1.10 的只读适配器。

从 v1.0.0 更新时，解压 v1.0.1 后双击 `双击安装.cmd` 即可。安装器会先
校验 SHA-256 并备份旧版本；如需回退，可双击 `双击恢复上一版本.cmd`。
