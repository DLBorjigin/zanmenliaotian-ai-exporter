# v1.0.10 微信更新兼容修复

新增 Windows 微信 4.1.15.13 的只读数据库适配，修复旧版本无法提取的问题。

- 使用精确版本适配和结构化 WCDB 配置定位，不开放任意未来版本。
- 每个数据库仍须通过其自身的 SQLCipher HMAC 校验，错误密钥不得用于导出。
- 2026-09-22 本机验证消息、会话、联系人和语音媒体四类数据库。
- 保留多库合并、发送者归属、文件消息识别、媒体分类及安装脚本编码修复。
- Windows 安装包包含离线语音解码器、whisper.cpp 与多语言模型。

## 下载与更新

下载 Assets 中的 `微信聊天导出工具-v1.0.10-Windows.zip`，完整解压到新文件夹，
双击 `双击安装.cmd`，安装成功后重新打开 Codex。旧用户操作相同，安装器会备份旧版。
不要下载 GitHub 自动生成的 Source code ZIP 来代替完整安装包。

## 验证边界与安全

实机检查覆盖密钥验证、稳定快照、已提交 WAL 处理和数据库结构；未读取聊天正文，
未重新验收具体聊天的图片、表情、文件、视频或语音转写。图片媒体密钥须另行授权验证。
不修改微信，不使用 Hook 或注入，不保存密钥或内存转储，不自动结束微信。
本版本仍仅支持 Windows；其他微信构建和 macOS 未因此获得兼容保证。
