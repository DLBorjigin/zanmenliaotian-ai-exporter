# v1.0.11 联系人列表导出

新增联系人专用导出命令，生成包含 Excel 和 CSV 的 ZIP。
按普通联系人、群聊、公众号候选和已识别系统账号分开输出。
导出昵称、备注、本地公开微信号、散列记录编号及好友关系状态。

注意：普通联系人不等于确认好友，所有好友关系均标记为未核实。
可能包含群成员、历史联系人或本人；公众号分类仅为前缀规则候选。
精确重复记录去重，内容冲突的记录保留。手机号、头像、扩展资料和聊天正文不读取。
CSV 对可能的公式内容进行转义，Excel 按文本存储。导出文件属于隐私资料，请勿上传公开仓库。

保持 Windows 微信 4.1.15.13 及既有精确版本适配，保留离线语音模型。
本次 96 项自动测试通过；联系人实际数量和分类效果依赖本地同步情况。

下载 `微信聊天导出工具-v1.0.11-Windows.zip`，完整解压到新文件夹，
双击 `双击安装.cmd`，安装成功后重新打开 Codex。
可以说：“导出我的本地联系人列表，按类型分开，保存为 Excel 和 CSV。”
工具会先请求联系人元数据导出及指定数据库只读内存检查授权。
