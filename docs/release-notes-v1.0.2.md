# v1.0.2 发布说明

本版本集中修复 Weixin 4.1.13.12 的图片、视频、表情和文件识别问题。

- 图片媒体配置可从同一微信实例的其他子进程中只读发现；
- 支持读取 Zstandard 压缩的消息内容和来源元数据；
- V2 WXGF 原图会如实标记，并尽可能同时生成可查看预览；
- 视频缩略图与完整视频严格区分；
- 重复表情缓存按内容去重，未知私有格式不再作为普通图片复制；
- 表情 CDN 补全默认关闭，启用时需要独立授权、受限微信域名和图片签名校验；
- 文件消息新增压缩内容分类和精确文件名解析测试；
- 共 71 项自动测试通过；表情 CDN 已在 `wxapp.tc.qq.com` 实机验证。

更新时解压 v1.0.2 后双击 `双击安装.cmd`。安装器会校验 SHA-256 并备份旧版，
需要回退时双击 `双击恢复上一版本.cmd`。
