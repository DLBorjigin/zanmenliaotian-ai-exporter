# v1.0.3 发布说明

本版本修复附件在 ZIP 中混放的问题。

- 普通图片进入 `assets/images/`；
- 视频及其 JPEG 封面进入 `assets/videos/`；
- 表情图片进入 `assets/emoticons/`；
- 语音和文件分别进入 `assets/audio/` 与 `assets/files/`；
- 分类依据是微信消息类型，不是文件扩展名；
- 清单、结构化消息和时间线继续保留原始消息类型与相对路径；
- 71 项自动测试全部通过；
- Weixin 4.1.13.12 实机验收中，图片、视频封面和 PNG 表情交叉放错数量均为 0。

从旧版更新时，完整解压 v1.0.3 后双击 `双击安装.cmd`。安装器会自动备份
上一版本，需要回退时可双击 `双击恢复上一版本.cmd`。
