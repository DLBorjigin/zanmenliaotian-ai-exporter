# v1.0.4 发布说明

本版本把容易混淆的四类媒体请求彻底分开。

- “图片”只包含普通图片消息；
- “表情”只包含表情消息；
- “视频”只包含经过文件签名验证的可播放原视频；
- “视频封面”只包含视频消息的图片缩略图；
- 只有用户明确要求两者时，原视频和封面才会同时导出；
- 本地缺少原视频时不再用封面冒充，并明确记录缺失状态；
- 经单独网络授权后，可从消息自带的受限微信 CDN 引用补全原视频，
  并验证下载、可选 AES 解密结果和视频容器签名；
- 用户只写到分钟的结束时间时，默认包含该分钟的全部 60 秒；
- 75 项自动测试全部通过。

从旧版更新时，完整解压 v1.0.4 后双击 `双击安装.cmd`。安装器会自动备份
上一版本，需要回退时可双击 `双击恢复上一版本.cmd`。
