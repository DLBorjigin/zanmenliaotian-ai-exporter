# v1.0.5 发布说明

这是公开版本 `v1.0.4` 之后的修复版。所有源码、运行时、安装包、说明文档和
GitHub tag 均统一使用 `v1.0.5`。

## 本次修复

- 修复部分消息已解析出联系人姓名、但因方向状态为空而被下游误判为无发送者；
- `messages.json` 新增 `sender_attribution`，分别说明发送者身份、方向和判定来源；
- Weixin 4.x 在状态为空但存在 `real_sender_id` 时，可安全恢复为他人发送；
- 旧版群聊可从保守验证的消息发送者前缀恢复联系人姓名；
- 真正无法判断的记录会明确标记未知，不会用群名称伪装成成员名称；
- 附件导出默认生成一个 `*-records.zip` 与按消息类型拆分的媒体 ZIP；
- 记录 ZIP 保留完整消息和附件映射，但不再重复包含媒体字节；
- 每份媒体只出现在一个分类 ZIP 中，不需要再次复制或手工打包；
- 只有明确要求单一自包含 ZIP 时才嵌入附件，且不会同时生成分类媒体 ZIP；
- 增加回归测试，验证默认输出只有记录包和所需分类包，记录包内没有附件副本；
- 修复跨多个 `message_N.db` 的同一聊天被覆盖和遗漏的问题；
- 大型媒体库改为按会话、月份、MD5 和文件名定向查找；
- 目录未完整读取时报告“索引不完整”，不再误报“文件不存在”。

## 保留的安全边界

- 默认本地、只读，不写入微信进程，不 Hook，不保存内存转储；
- 图片、表情、原视频和视频封面严格分开；
- 未缓存原视频不会通过自动操作微信界面强制下载；
- 密钥、数据库路径和明文数据库不会进入导出包。

## 安装

下载 `微信聊天导出工具-v1.0.5-Windows.zip`，完整解压后双击
`双击安装.cmd`，然后完全关闭并重新打开 Codex。
