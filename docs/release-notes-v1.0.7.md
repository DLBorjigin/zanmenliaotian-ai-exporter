# v1.0.7 发布说明

这是 v1.0.6 之后的本地语音转文字版本。源码、运行时、安装包、说明文档和
GitHub tag 统一使用 `v1.0.7`。

## 新功能

- 支持把选定聊天、时间范围内的微信语音批量转成文字；
- 从 Weixin 4.x `media_*.db` 精确匹配语音，保留原始 `.silk`；
- 在本机把 SILK 解码为临时 16 kHz 音频，再由 whisper.cpp 离线识别；
- 转写文字按原消息的时间和发送者写回 `transcript.md`；
- `messages.json` 和 `manifest.json` 保存转写状态、语言、引擎、模型及
  `machine_generated` 标记；
- 单条语音失败、静音、超时或无结果不会中断其他消息的导出。

## 安装与使用

普通用户只需下载 `微信聊天导出工具-v1.0.7-Windows.zip`，完整解压，双击
`双击安装.cmd`，然后完全关闭并重新打开 Codex。发行包已经包含 Windows x64
运行程序和多语言 `base` 模型；不需要另装 Python、FFmpeg、模型或申请云端 API。

安装后可以直接说：

> 导出群聊“项目组”今天 09:00 到 18:00 的全部语音，并在本机转成文字。

第一次识别也不会下载模型。识别使用 CPU，电脑越慢、语音越多，等待时间越长。

## 隐私与准确性

- 语音识别全程在本机离线完成，不上传语音或转写文字；
- 仍需分别确认复制所选语音、读取语音正文和执行本地转写；
- 临时 PCM/WAV 和识别临时文件使用后删除；
- 原始 `.silk` 放在独立音频 ZIP 中，便于回听复核；
- 自动转写可能受方言、口音、噪音、多人重叠和专有名词影响，重要内容应回听确认；
- 默认不修改微信、不 Hook、不保存内存转储、不自动结束微信进程。

## 组件与可审计性

- whisper.cpp：固定在 `b4938` Windows x64 官方发行包；
- 模型：OpenAI Whisper 多语言 `base` 模型（约 141 MiB）；
- SILK 解码：从固定的 `kn007/silk-v3-decoder` 源码提交本机编译；
- 组件来源、提交和校验值记录在 `vendor/voice-runtime.json`；
- 第三方许可证随源码和安装包一起提供。

## 保留修复

保留 v1.0.6 的文件消息复合类型识别，以及此前版本的多数据库合并、发送者归属、
定向媒体查找和图片/表情/原视频/视频封面严格分离。
